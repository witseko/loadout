# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in issues, pull requests, discussions, and any other project space.

## In short

- Be respectful and patient. Assume good intent.
- Criticize code and ideas, not people.
- No harassment, insults, personal attacks, or sexual language or imagery.
- Do not publish private information about anyone without their permission.

## Enforcement

The maintainer, [witseko](https://github.com/witseko), reviews every report and keeps the reporter's identity private. The maintainer can edit or remove comments, commits, and issues, and can block people who break this code, temporarily or permanently.

To report a problem, use GitHub's **Report content** option on the comment or issue, or contact the maintainer through their GitHub profile.
